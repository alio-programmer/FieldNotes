# Fieldnotes

A small, local-first project log with a quiet graph-paper workspace, target checklists, and automatic completion tracking.

## Run it (React + Vite + Tailwind)

Requires Node.js 18 or newer. From this folder, run:

```powershell
npm install
npm run dev
```

Then open [http://localhost:4173](http://localhost:4173). Press Ctrl+C in the terminal to stop the server.

Build for production with `npm run build` and preview with `npm run preview`.

Projects are stored in this browser on this device using local storage. They are not synced to an account or server.
